# Direktori Foto Background Hero Provinsi (Drainusantara)

Cukup letakkan **4 hingga 5 foto** di folder ini. Foto-foto ini akan **otomatis menjadi background hero** untuk halaman Provinsi yang bersangkutan, sekaligus **otomatis diwarisi** oleh semua halaman Kota dan Kecamatan di bawah provinsi tersebut.

## Format File yang Didukung:
Format disarankan: `.webp` (atau `.jpg`).

## Daftar Nama File Sesuai Provinsi:
1. **DKI Jakarta**:
   - `dki-jakarta.webp`
   - *Otomatis dipakai oleh*: Provinsi DKI Jakarta, Kota Jakarta Timur, Jakarta Selatan, Jakarta Barat, Jakarta Utara, Jakarta Pusat, serta seluruh kecamatannya (Cakung, Duren Sawit, Tebet, Kebon Jeruk, Kelapa Gading, dll.).
2. **Jawa Barat**:
   - `jawa-barat.webp`
   - *Otomatis dipakai oleh*: Provinsi Jawa Barat, Kota Bogor, Depok, Bekasi, Bandung, Cimahi, serta seluruh kecamatannya.
3. **Banten**:
   - `banten.webp`
   - *Otomatis dipakai oleh*: Provinsi Banten, Tangerang Kota, Tangerang Selatan (BSD/Bintaro/Pamulang), Serang, Cilegon, dll.
4. **Jawa Tengah**:
   - `jawa-tengah.webp`
   - *Otomatis dipakai oleh*: Provinsi Jawa Tengah, Kota Semarang, serta seluruh kecamatannya (Candisari, Banyumanik, Simpang Lima, dll.).
5. **Lampung**:
   - `lampung.webp`
   - *Otomatis dipakai oleh*: Provinsi Lampung, Kota Bandar Lampung, serta seluruh kecamatannya (Kedaton, Way Halim, Teluk Betung, Sukarame, dll.).

---
*Catatan: Jika ada 1 kecamatan tertentu yang ingin menggunakan foto khusus, Anda tetap bisa menaruh foto tersebut di `public/images/areas/districts/{slug-kota}-{slug-kecamatan}.webp`.*
